01 · Canonical first
事实、来源、时间和 outbox 在 PostgreSQL 事务内持久化。向量失败不应让已经确认的权威事实消失。
02 · Rebuildable views
向量索引和 AGE 图是从权威数据派生的检索结构。它们可以落后、失败或重建，但不能自行决定事实真伪。
03 · Explicit boundaries
大对象字节由内容寻址存储管理，Temporal 只在需要持久编排时启用；不把每条记忆写入都变成分布式工作流。


03 / RETRIEVAL ENGINE
回答“过去说过什么”，不能只靠相似度。
多通道发现候选，最后必须回到 PostgreSQL 验证租户、时间、来源和权限。点选任一召回通道，查看它解决的问题与不能解决的问题。

Candidate ≠ Canonical truth
向量相近、图路径可达、关键词匹配，只能证明“值得检查”，不能证明“当前有效且允许读取”。所有候选都必须经过权威事实过滤。
tenant authorization → known_at → valid_at → provenance → bounded result
实际混合检索的运行能力应通过 GET /v1/capabilities 确认；中文真实语料上的检索质量尚未达到可宣称完成的独立验收状态。
