Data mapping / Transparency

Each filament bundle = a stable semantic domain; strand count is a capped monotonic function of the number of claims in that domain; blue highlight = selected claim or locally matched evidence. Layout is deterministic per domain and record identity. Spatial distance and curve curvature are not similarity scores or causal relationships.

The API currently exposes claim browse and event replay. This first edition does not invent AGE topology edges, embeddings or model-quality metrics.
