Bitemporal

双时态，不混用

valid_at 是世界什么时候如此，known_at 是我们什么时候相信。两个问题，两套答案。

Trusted cardinality

基数由库决定

一个房间只能有一条当前温度。这条规则写在租户策略表里，模型无权修改。

Soft forget

遗忘可撤回，审计不可

删除只是不再相信；行、事件与时间线仍在，随时能回答“当时为什么这么写”。

先跑通一条链路

下面四条命令覆盖了「探活 → 探能力 → 写一句自然语言 → 回看台账」的完整闭环。

# 1. 进程活着（无需鉴权）
curl -s $API/v1/health

# 2. 这个实例到底开了哪些能力
curl -s -H "Authorization: Bearer $KEY" $API/v1/capabilities

# 3. 写一句自然语言：抽取 → 判重/判矛盾 → 双时态入库
curl -s -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"text":"我不喜欢卧室太吵","source_id":"demo:1"}' \
  $API/v1/memories/process

# 4. 回看台账（含已被替换的历史版本）
curl -s -H "Authorization: Bearer $KEY" \
  "$API/v1/memories?include_superseded=true&limit=20"
